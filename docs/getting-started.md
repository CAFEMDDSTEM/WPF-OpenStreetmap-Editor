# Getting Started

## Open a map

- Use **File > Open** to load an existing map file.
- Use **File > New** to start a blank document.
- Use the layer panel to pick the active imagery or data layer.

## Navigate

- Drag the map to pan.
- Use the mouse wheel or the zoom buttons to zoom.
- Press **F1** to open the built-in Help and About window.

## Edit features

- Use **S** to select features.
- Use **V** to box-select.
- Use **A** to draw lines.
- Use **M** to move selected features.
- Use **R** to rotate selected features.
- Use **Q** to orthogonalize selected features.
- Press **Insert** to add a node at the map center.

## Save and upload

- Use **Ctrl+S** to save the current map.
- Use **File > Save as** to write to a new file.
- Use the OSM download and upload tools after you have selected an area.

## Need more detail

Open **Help > Help and About** for the in-app usage notes, keyboard shortcuts, and license text.
